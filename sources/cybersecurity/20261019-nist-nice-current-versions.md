## <span id="Components " class="ck-anchor"></span>**NICE FRAMEWORK COMPONENTS**

NICE Framework Components — Work Role Categories, Work Roles, Competency Areas, and Task, Knowledge, and Skill statements — are provided separately from the NICE Framework structure (SP 800-181 Rev. 1) in the formats below. 

**CURRENT VERSION: 2.2.0 (April 28, 2025)**

- [NIST Cybersecurity and Privacy Reference Tool (CPRT)](https://csrc.nist.gov/projects/cprt/catalog#/cprt/framework/version/SP_800_181_2_1_0/home): Browsable and searchable version of the NICE Framework; includes streamlined XLSX and JSON downloads (v2.2.0 coming soon)

- <a href="/document/nice-framework-components-v220" class="media-link-ga" data-entity-substitution="canonical" data-entity-type="media" data-entity-uuid="eb7aad2a-5569-4371-8107-bcc5acb26081" data-file-url="/system/files/documents/2026/06/24/NICE%20Framework%20Components%20v2.2.0.xlsx" title="NICE Framework Components v2.2.0">Spreadsheet (XLSX)</a>

- [JSON Document](https://csrc.nist.gov/csrc/media/Projects/cprt/documents/nice/v2-2-0_nf_components.json) (read our <a href="/itl/applied-cybersecurity/nice/nice-framework-resource-center/faq-nice-framework-data-json-format" data-entity-type="node" data-entity-uuid="915bcd03-6fba-4dc8-943e-9bce0e9696ad" data-entity-substitution="canonical" title="FAQ for NICE Framework Data in JSON Format">JSON FAQ</a>) 

- [NICE Framework Online](https://niccs.cisa.gov/tools/nice-framework): Browsable and searchable version of the NICE Framework hosted by the National Initiative for Cybersecurity Careers and Studies (NICCS) under the Cybersecurity and Infrastructure Security Agency (CISA)

## <span id="Publications " class="ck-anchor"></span>nice framework Publications 

**NICE FRAMEWORK (NIST SP 800-181r1)**

NIST Special Publication 800-181 revision 1: [The Workforce Framework for Cybersecurity (NICE Framework)](https://doi.org/10.6028/NIST.SP.800-181r1) (November 2020). This document details the structure and use of the NICE Framework. NICE Framework components are separately maintained (see below).

- [SP 800-181 Homepage](https://csrc.nist.gov/publications/detail/sp/800-181/rev-1/final)
- [NIST SP 800-181r1 (PDF)](https://nvlpubs.nist.gov/nistpubs/SpecialPublications/NIST.SP.800-181r1.pdf)

**NICE FRAMEWORK COMPETENCY AREAS (NISTIR 8355)**

NIST Interagency/Internal Report 8355: [NICE Framework Competency Areas: Preparing a Job-Ready Cybersecurity Workforce](https://doi.org/10.6028/NIST.IR.8355) (June 2023) is a companion paper to NIST SP 800-181 and provides more detail about NICE Framework Competency Areas, including their evolution, development, and stakeholder uses.

- [NISTIR 8355 Homepage](https://csrc.nist.gov/pubs/ir/8355/final)
- [NISTIR 8355 (PDF)](https://doi.org/10.6028/NIST.IR.8355)

##  <span id="crosswalks" class="ck-anchor"></span>NICE FRAMEWORK mappings

*If you have mapped your credential or materials to the NICE Framework and would like it to be added here or if you would like more information on how to map your content, please contact us at* NICEFramework \[at\] nist.gov (subject: NICE%20Framework%20Mapping) (*NICEFramework\[at\]nist\[dot\]gov*)*.*

**NICE Framework Components to CSF Mapping**  
A mapping of NICE Framework Components v2.0.0 to <a href="/cyberframework" data-entity-type="node" data-entity-uuid="d93e537b-1852-4185-a8e4-b5ea1fe460de" data-entity-substitution="canonical" title="Cybersecurity Framework">NIST Cybersecurity Framework (CSF) v2.0</a> connects CSF Categories and Subcategories with NICE Framework Work Roles using the [OLIR Comparison Report](https://csrc.nist.gov/projects/olir/coverage-report#/olir/coverage-report) function (select CSF 2.0 under “NIST Publication”, then NICE Framework Components under “Reference”). A color-coded version of the mapping spreadsheet is available for download <a href="/document/nice-framework-components-csf-crosswalk-v200-v2-september-2025" class="media-link-ga" data-entity-substitution="canonical" data-entity-type="media" data-entity-uuid="019594de-df86-4aee-a26a-d5fcbf1a9961" data-file-url="/system/files/documents/2025/11/14/NICE%20Framework%20to%20CSF%20Mapping%20-%20v2.0.0%20to%20V2%20-%20September%202025.xlsx" title="NICE Framework Components to CSF Crosswalk - v2.0.0 to v2 - September 2025">here</a>.

**O\*NET-SOC Codes**  
A crosswalk between NICE Framework Work Roles and Work Role Categories and cybersecurity-related [O\*NET-SOC codes](https://www.onetcenter.org/taxonomy.html) was developed in collaboration between the NICE Program Office and Georgetown's Center on Security and Emerging Technology (CSET). The crosswalk is maintained by CSET and is available [here](https://eto.tech/dataset-docs/nice-onet-crosswalk/).

**Cybersecurity Credentials Collaborative**  
Users interested in comparing NICE Framework Work Roles to industry certifications issued by members of the [Cybersecurity Credentials Collaborative (C3)](https://cybersecuritycc.org/) may use the Excel spreadsheet available for download <a href="/document/c3-credentials-nice-framework-work-role-mapping-v200-apr-2025" class="media-link-ga" data-entity-substitution="canonical" data-entity-type="media" data-entity-uuid="702513fd-0d98-4e07-beb0-7bc01a234dbc" data-file-url="/system/files/documents/2025/04/16/C3%20Credentials%20Mapping%20to%20NICE%20Work%20Roles%20-%20v2.0.0%20-%20March%202025.xlsx" title="C3 Credentials to NICE Framework Work Role Mapping - v2.0.0 Apr 2025">here</a>. 

**Jones & Bartlett Learning Mapping**  
This [mapping](https://www.jblearning.com/science-technology/computing/cybersecurity-nice-work-roles) identifies how Jones & Bartlett Learning resources align with key NICE Framework Work Roles. Includes a percentage that indicates alignment to TKS statements for each role.
