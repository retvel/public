# Security+

CompTIA Security+ is a globally recognized cybersecurity certification that helps you build and validate the practical cybersecurity skills needed to perform core security functions and pursue a career in cybersecurity. Security+ V7 is available today, while the newest version, Security+ V8, is expected to launch on or around November 17, 2026. If you're ready to certify now, V7 remains a strong option. If you're planning ahead, Security+ V8 offers expanded coverage of areas such as AI-related risks, security operations, and modern environments.
